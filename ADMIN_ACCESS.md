## 🚀 Как войти в админ-панель

### Вариант 1: Прямая ссылка
Введите в адресной строке браузера:
```
http://localhost:5000/admin
```

### Вариант 2: Добавить в закладки
1. Откройте страницу `http://localhost:5000/admin`
2. Добавьте её в закладки браузера (Ctrl+D)
3. Используйте закладку для быстрого доступа

## 🔄 Изменение пароля

### Способ 1: Через скрипт
Если вы хотите изменить пароль на свой:

1. Откройте файл `update_admin_password.py`
2. Измените строку с паролем:
```python
admin.set_password('ВАШ_НОВЫЙ_ПАРОЛЬ')
```
3. Запустите скрипт:
```bash
python update_admin_password.py
```

### Способ 2: Через Python консоль
```python
from app import app
from models import db, User

with app.app_context():
    admin = User.query.filter_by(username='admin').first()
    admin.set_password('ВАШ_НОВЫЙ_ПАРОЛЬ')
    db.session.commit()
```

## 🛡️ Рекомендации по безопасности

### ✅ Что нужно сделать:

1. **Измените пароль сразу после установки**
   - Используйте уникальный сложный пароль
   - Минимум 12 символов
   - Комбинация букв, цифр и спецсимволов

2. **Используйте HTTPS в продакшене**
   - Установите SSL-сертификат
   - Настройте редирект с HTTP на HTTPS

3. **Ограничьте доступ к серверу**
   - Используйте файрвол
   - Настройте IP-whitelist при необходимости

4. **Регулярно делайте резервные копии**
   - База данных `instance/database.db`
   - Папка с изображениями `static/uploads/`

5. **Измените SECRET_KEY в продакшене**
   - В файле `app.py` найдите:
   ```python
   app.config['SECRET_KEY'] = 'your-secret-key-change-this-in-production'
   ```
   - Замените на уникальную строку

### ❌ Что НЕ нужно делать:

- ❌ Не публикуйте пароль в открытом доступе
- ❌ Не используйте простые пароли типа "123456"
- ❌ Не оставляйте DEBUG=True в продакшене
- ❌ Не давайте доступ к серверу посторонним лицам

## 📝 Генерация сложного пароля

Можете использовать эти команды для генерации случайного пароля:

**Python:**
```python
import secrets
import string

alphabet = string.ascii_letters + string.digits + '!@#$%^&*'
password = ''.join(secrets.choice(alphabet) for i in range(16))
print(password)
```

**Linux/Mac:**
```bash
openssl rand -base64 16
```

**Windows PowerShell:**
```powershell
-join ((48..57) + (65..90) + (97..122) | Get-Random -Count 16 | % {[char]$_})
```
