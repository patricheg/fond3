# 🚀 Установка поддержки множественных изображений

## ⚠️ ВАЖНО: Для уже работающих установок

Если у вас уже есть работающая установка сайта, выполните следующие шаги:

### Шаг 1: Остановите сервер

Нажмите `Ctrl+C` в терминале, где запущен сервер.

### Шаг 2: Удалите старую базу данных

**Windows PowerShell:**
```powershell
Remove-Item instance\database.db -Force
```

**Linux/Mac:**
```bash
rm instance/database.db
```

**Или** просто удалите файл `instance/database.db` вручную через проводник.

### Шаг 3: Запустите приложение заново

```bash
python app.py
```

Приложение автоматически создаст новую базу данных с поддержкой множественных изображений!

### Шаг 4: Добавьте тестовые данные (опционально)

```bash
python add_sample_data.py
```

## ✅ Для новых установок

## 📸 Тестирование множественной загрузки

1. Войдите в админ-панель
2. Перейдите в "Сборы" → "Добавить"
3. В поле "Загрузить изображения" выберите **несколько файлов**
   - Windows: Ctrl + клик
   - Mac: Cmd + клик
4. Увидите предпросмотр всех файлов
5. Сохраните
6. На главной странице увидите **слайдер** с вашими изображениями!

## ❓ Возможные проблемы

### Ошибка "no such column: images_json"

✔️ **Решение:** Удалите старую базу данных и перезапустите приложение (см. Шаг 1-3 выше)

### Слайдер не работает

✔️ **Проверьте:**
- Загружено больше 1 изображения
- JavaScript включен в браузере
- Очистите кэш (Ctrl + F5)

### Изображения не загружаются

✔️ **Проверьте:**
- Формат файлов (PNG, JPG, GIF, WEBP)
- Размер файлов (до 5 МБ каждый)
- Папка `static/uploads/` существует
