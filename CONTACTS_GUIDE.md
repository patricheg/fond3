# 📞 Управление контактами - Инструкция

## Теперь контакты в футере управляются из админки!

Вся контактная информация в футере сайта теперь динамическая и редактируется через админ-панель.

---

## 📝 Как обновить контакты

### 1. Войдите в админ-панель
```
https://ваш-домен.com/admin/login
```

### 2. Перейдите в раздел "Контакты"
В левом меню админ-панели выберите **"Контакты"**

### 3. Заполните поля
Доступные поля:

#### **Основные контакты:**
- **Телефон** - отображается в футере с иконкой телефона
  - Формат: `+375 (XX) XXX-XX-XX`
  - Пример: `+375 (29) 123-45-67`
  
- **Email** - отображается в футере с иконкой конверта
  - Формат: `email@domain.com`
  - Пример: `info@sportfund.by`

#### **Социальные сети:**
- **VKontakte** - ссылка на группу VK
  - Формат: полная ссылка
  - Пример: `https://vk.com/sportfund`
  
- **Telegram** - ссылка на канал или чат
  - Формат: полная ссылка или username
  - Пример: `https://t.me/sportfund` или `sportfund`
  
- **Instagram** - ссылка на профиль
  - Формат: полная ссылка
  - Пример: `https://instagram.com/sportfund`
  
- **Viber** - номер телефона для Viber
  - Формат: номер с кодом страны без пробелов
  - Пример: `+375291234567`
  
- **WhatsApp** - номер телефона для WhatsApp
  - Формат: номер с кодом страны без пробелов
  - Пример: `375291234567` (без +)

#### **Дополнительная информация:**
- **Доп. информация** - любая текстовая информация
  - Отображается в модальном окне "Помочь сейчас"

### 4. Сохраните изменения
Нажмите кнопку **"Сохранить"**

---

## 🎯 Где отображаются контакты

### 1. **Футер сайта (на всех страницах)**
- Телефон и Email в разделе "Контакты"
- Социальные сети в разделе "Социальные сети"
- Автоматически становятся кликабельными ссылками

### 2. **Модальное окно "Помочь сейчас"**
- На детальных страницах сборов
- При нажатии на кнопку "Помочь сейчас"
- Отображает все заполненные контакты

### 3. **Структурированные данные (SEO)**
- Автоматически используются в Schema.org разметке
- Отображаются в результатах поиска Google/Яндекс
- Используются при публикации в социальных сетях

## ✨ Особенности

### **Автоматические ссылки:**
- **Телефон** → кликабельная ссылка для звонка с мобильных
- **Email** → открывает почтовый клиент
- **Социальные сети** → открываются в новой вкладке

### **Умная обработка:**
- Если Telegram указан как `sportfund`, автоматически преобразуется в `https://t.me/sportfund`
- WhatsApp номер автоматически форматируется для ссылки `https://wa.me/...`
- Viber создает ссылку для прямого чата

### **Отображение только заполненных полей:**
- Пустые поля автоматически скрываются
- Футер адаптируется под заполненные данные
- Нет "пустых" иконок в социальных сетях

### **Резервные значения:**
- Если контакты не заполнены, отображаются значения по умолчанию
- Email по умолчанию: `info@sportfund.by`
- Телефон по умолчанию: `+375 (XX) XXX-XX-XX`

## ⚠️ Важно

1. **Не удаляйте запись контактов** в базе данных
   - Система использует первую (единственную) запись ContactInfo
   - При удалении создастся новая с дефолтными значениями

2. **Проверяйте ссылки на соцсети**
   - Убедитесь, что профили существуют и активны
   - Используйте полные ссылки с `https://`

3. **Номера телефонов**
   - Для международных звонков добавляйте код страны
   - Формат для WhatsApp отличается от формата для отображения
