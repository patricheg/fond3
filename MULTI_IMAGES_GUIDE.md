# 🖼️ Руководство по работе с несколькими изображениями

## Новая возможность: множественная загрузка изображений!

Теперь для каждого материала (сбора, новости, турнира) можно загрузить **несколько изображений**, которые будут отображаться в виде **слайдера/карусели**!

---

## ✨ Возможности

### 📸 Загрузка
- **Несколько файлов за раз** - выберите сразу все нужные изображения
- **Предпросмотр** - увидите все выбранные изображения перед сохранением
- **Управление** - можете удалить ненужные и добавить новые при редактировании

### 🎬 Отображение
- **Автоматический слайдер** - изображения автоматически отображаются в карусели
- **Навигация** - кнопки "вперед/назад" и точки навигации
- **Адаптивность** - красиво работает на всех устройствах

---

## 🎯 Как использовать

### Добавление нового материала с несколькими изображениями

1. **Войдите в админ-панель**: http://127.0.0.1:5000/admin

2. **Выберите раздел** (Сборы / Новости / Турниры)

3. **Нажмите "Добавить"**

4. **Заполните форму**

5. **В поле "Загрузить изображения":**
   - Нажмите кнопку "Выберите файлы"
   - В открывшемся окне выберите **несколько изображений**
     - Windows: Ctrl + клик для выбора нескольких файлов
     - Mac: Cmd + клик
     - Или выделите область мышью
   - Нажмите "Открыть"

6. **Увидите предпросмотр** всех выбранных изображений

7. **Нажмите "Сохранить"**

8. **Результат**: На сайте появится красивый слайдер с вашими изображениями!

---

### Редактирование материала с изображениями

1. **Откройте материал для редактирования**

2. **Увидите все текущие изображения** в виде миниатюр

3. **Управление изображениями:**
   
   **Удалить изображение:**
   - Снимите галочку "Сохранить" под изображением
   - Это изображение будет удалено при сохранении

   **Добавить новые изображения:**
   - Выберите новые файлы через поле загрузки
   - Они добавятся к существующим

   **Заменить все изображения:**
   - Снимите галочки со всех текущих
   - Загрузите новые файлы

4. **Нажмите "Сохранить"**

---

## 🎨 Как выглядит слайдер

### На карточках (главная страница, списки):
```
┌─────────────────────────────┐
│  ◄    [Изображение]     ►   │  ← Кнопки навигации
│                             │
│        ● ○ ○ ○              │  ← Точки (индикаторы)
└─────────────────────────────┘
```

### На детальных страницах:
```
┌─────────────────────────────┐
│  ◄                      ►    │
│                             │
│    [Большое изображение]     │
│                             │
│        ● ○ ○ ○              │
└─────────────────────────────┘
```

### Управление:
- **Стрелки влево/вправо** - переключение изображений
- **Точки внизу** - переход к конкретному изображению
- **Автоматическая подсветка** активного изображения

## 💡 Советы и рекомендации

### ✅ Лучшие практики:

1. **Количество изображений:**
   - Оптимально: 3-5 изображений
   - Максимум: без ограничений, но не перебарщивайте

2. **Порядок изображений:**
   - Первое изображение - самое важное (главное фото)
   - Остальные - дополнительные ракурсы, детали

3. **Для сборов:**
   - Фото спортсмена крупным планом
   - Спортсмен в действии
   - Достижения, медали
   - Тренировки
   - Личные фото

4. **Для новостей:**
   - Главное фото события
   - Участники мероприятия
   - Детали, момент действия
   - Награждение, эмоции

5. **Для турниров:**
   - Баннер турнира
   - Место проведения
   - Прошлые турниры
   - Призы, награды

### ⚠️ Ограничения:

- **Размер файла**: до 5 МБ каждый
- **Форматы**: PNG, JPG, GIF, WEBP
- **Рекомендуемое разрешение**: 800×600 или 1200×800

## 🔧 Технические детали

### Хранение:
- Изображения хранятся на сервере в `static/uploads/`
- Ссылки сохраняются в базе данных в JSON формате
- Автоматическое удаление при удалении материала

### Производительность:
- Изображения загружаются быстро
- Слайдер работает без задержек
- Адаптивные размеры для разных экранов

### Безопасность:
- Проверка типов файлов
- Ограничение размера
- Уникальные имена файлов

## 🆘 Устранение проблем

### Не удается выбрать несколько файлов

✔️ **Windows**: Удерживайте Ctrl и кликайте на файлы  
✔️ **Mac**: Удерживайте Cmd и кликайте на файлы  
✔️ Или выделите мышью область с файлами

### Предпросмотр не показывает изображения

✔️ Убедитесь, что выбрали правильные форматы (PNG, JPG, GIF, WEBP)  
✔️ Проверьте размер файлов (не более 5 МБ каждый)  
✔️ Попробуйте обновить страницу

### Слайдер не переключается

✔️ Убедитесь, что загружено больше 1 изображения  
✔️ Проверьте, что JavaScript включен в браузере  
✔️ Попробуйте очистить кэш (Ctrl + F5)

### Старые изображения не удаляются

✔️ Снимите галочку "Сохранить" под изображением  
✔️ Обязательно нажмите "Сохранить" в форме  
✔️ Проверьте, что материал сохранен успешно
