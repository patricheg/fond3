# История изменений

## [Версия 1.3] - 15.01.2026

### ✨ Новые возможности

#### 📄 Страница "О нас"
- **Полная страница о фонде**: Создана новая страница с информацией об организации
- **Редактируемый контент**: Все тексты можно изменять через админ-панель
- **Три блока текста**:
  - Основная информация о фонде
  - Наша миссия
  - Наше видение
- **Галерея изображений**: Загрузка документов, достижений и фотографий
- **Просмотр в полном размере**: Клик по изображению открывает модальное окно
- **Управление изображениями**: Добавление и удаление изображений в один клик
- **Автоматическая инициализация**: Страница создается с дефолтным контентом

#### 🎨 Улучшения интерфейса
- **Красивое отображение**: Современный дизайн с карточками и иконками
- **Сетка документов**: Адаптивная сетка с overlay-эффектом при наведении
- **Анимации**: Плавные переходы при наведении
- **Навигация**: Ссылка "О нас" добавлена в главное меню и админ-панель

#### 🔧 Технические улучшения
- **Новая модель AboutPage**: Singleton-модель для страницы "О нас"
- **AJAX удаление**: Удаление изображений без перезагрузки страницы
- **Миграция БД**: Скрипт `migrate_about.py` для обновления базы данных
- **Документация**: Подробное руководство `ABOUT_PAGE_GUIDE.md`

## [Версия 1.2] - 15.01.2026

### ✨ Новые возможности

#### 📸 Множественные изображения
- **Слайдер изображений**: Карусель для просмотра нескольких фото
- **Навигация**: Кнопки "вперед/назад" и точки для перехода
- **Поддержка множественной загрузки**: Выбор нескольких файлов за раз
- **Предпросмотр**: Просмотр всех загруженных изображений перед сохранением

#### 🎨 Улучшения дизайна
- **Адаптивный слайдер**: Работает на всех устройствах
- **Стили карточек**: Кнопки теперь всегда внизу и по центру
- **Гибкая верстка**: Карточки одинаковой высоты независимо от контента

## [Версия 1.1] - 15.01.2026

### ✨ Новые возможности

#### 📸 Загрузка изображений на сервер
- **Загрузка файлов**: Теперь можно загружать изображения прямо с компьютера
- **Поддерживаемые форматы**: PNG, JPG, JPEG, GIF, WEBP
- **Ограничение размера**: До 5 МБ на файл
- **Предпросмотр**: Мгновенный предпросмотр изображения перед сохранением

#### 🔧 Улучшения функционала
- Автоматическая генерация уникальных имен файлов
- Автоматическое удаление старых изображений при замене
- Удаление изображений при удалении записи
- Валидация типов и размеров файлов

#### 💾 Управление файлами
- Папка для хранения: `static/uploads/`
- Автоматическое создание папки при запуске
- Безопасное сохранение файлов

### 🎨 Улучшения интерфейса

#### Админ-панель
- Новое поле для загрузки файлов во всех формах
- Предпросмотр текущего изображения при редактировании
- Подсказки и инструкции по загрузке
- Стилизованная кнопка выбора файла

#### JavaScript
- Функция предпросмотра изображений
- Валидация типов файлов на клиенте
- Проверка размера перед загрузкой
- Автосохранение форм в localStorage
- Счетчик символов для текстовых полей

### 📝 Документация
- Создано руководство по загрузке: `UPLOAD_GUIDE.md`
- Обновлен основной README
- Добавлены примеры использования

## [Версия 1.0] - 15.01.2026

### 🎉 Первый релиз

#### Основной функционал
- Публичная часть сайта с главной страницей
- Страницы сборов, новостей и турниров
- Детальные страницы для каждого материала
- Защищенная админ-панель
- Полная система управления контентом

#### База данных
- SQLite для хранения данных
- Модели: User, Fundraiser, News, Tournament
- Автоматическая инициализация БД

#### Дизайн
- Современный адаптивный дизайн
- Поддержка мобильных устройств
- Анимации и переходы
- Font Awesome иконки

#### Функции админ-панели
- Добавление/редактирование/удаление сборов
- Управление новостями
- Создание турниров
- Статистика на главной панели
- Защищенная авторизация
