## 📋 Требуется ручная настройка

### 1. Изображения (Критично!) 🔴
- [ ] Создать `static/images/logo.png` (512x512px)
- [ ] Создать `static/images/og-image.jpg` (1200x630px)
- [ ] Создать `static/images/favicon.ico`
- [ ] **Инструкция**: см. `create_seo_images.md`

### 2. Регистрация в поисковых системах 🟡
- [ ] **Google Search Console**
  - Зарегистрировать сайт: https://search.google.com/search-console
  - Подтвердить владение
  - Отправить sitemap: `https://ваш-домен.com/sitemap.xml`
  
- [ ] **Яндекс Вебмастер**
  - Зарегистрировать сайт: https://webmaster.yandex.ru
  - Подтвердить владение
  - Отправить sitemap: `https://ваш-домен.com/sitemap.xml`

### 3. Аналитика (Рекомендуется) 🟡
- [ ] **Google Analytics**
  - Создать аккаунт: https://analytics.google.com
  - Получить ID отслеживания
  - Добавить код в `templates/base.html`
  
- [ ] **Яндекс.Метрика**
  - Создать счетчик: https://metrika.yandex.ru
  - Получить ID
  - Добавить код в `templates/base.html`

### 4. SSL сертификат (Критично для SEO!) 🔴
- [ ] Установить SSL сертификат (Let's Encrypt бесплатно)
- [ ] Настроить редирект HTTP → HTTPS
- [ ] Обновить все внутренние ссылки на HTTPS

### 5. Производительность 🟢
- [ ] Оптимизировать изображения (WebP формат)
- [ ] Настроить сжатие GZIP на сервере
- [ ] Настроить кэширование статических файлов
- [ ] Минифицировать CSS и JS (production)

### 6. Социальные сети 🟢
- [ ] Обновить ссылки на реальные социальные профили в `base.html`
- [ ] Создать профили, если их нет:
  - ВКонтакте
  - Telegram канал
  - Instagram (или другие платформы)
- [ ] Добавить реальные контакты в футере

## 🧪 Проверка после настройки

### 1. Тестирование SEO
Проверьте сайт с помощью:
- **Google PageSpeed Insights**: https://pagespeed.web.dev/
- **Google Mobile-Friendly Test**: https://search.google.com/test/mobile-friendly
- **Schema Markup Validator**: https://validator.schema.org/
- **Open Graph Debugger**: https://www.opengraph.xyz/
- **Facebook Sharing Debugger**: https://developers.facebook.com/tools/debug/

### 2. Проверка технических файлов
```bash
# Проверить robots.txt
curl https://ваш-домен.com/robots.txt

# Проверить sitemap.xml
curl https://ваш-домен.com/sitemap.xml

# Проверить что HTTPS работает
curl -I https://ваш-домен.com
```

### 3. Проверка индексации
После регистрации в поисковых системах (через 1-2 недели):
```
# В Google
site:ваш-домен.com

# В Яндекс
site:ваш-домен.com
```

### 4. Проверка мобильной версии
- Откройте сайт на телефоне
- Используйте Chrome DevTools → Toggle Device Toolbar
- Проверьте все страницы

## ⚠️ Важные замечания

1. **Домен в robots.txt**: Не забудьте обновить домен в `templates/robots.txt`
