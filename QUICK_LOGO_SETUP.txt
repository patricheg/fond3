┌──────────────────────────────────────────────────────────────┐
│ 🚀 СПОСОБ 1: АВТОМАТИЧЕСКИЙ (РЕКОМЕНДУЕТСЯ)                 │
└──────────────────────────────────────────────────────────────┘

1. Установите Pillow (если еще не установлен):
   
   pip install Pillow

2. Сохраните ваше изображение логотипа куда-нибудь 
   (например, на рабочий стол как logo_source.png)

3. Запустите скрипт:
   
   python create_favicons.py путь\к\вашему\logo_source.png
   
   Пример:
   python create_favicons.py C:\Users\pd\Desktop\logo.png

4. Готово! Все файлы автоматически созданы в static/images/

5. Запустите сайт и проверьте:
   
   python app.py
   Откройте http://127.0.0.1:5000


┌──────────────────────────────────────────────────────────────┐
│ 🔧 СПОСОБ 2: ВРУЧНУЮ (ЕСЛИ НЕТ PILLOW)                      │
└──────────────────────────────────────────────────────────────┘

1. Перейдите на сайт: https://favicon.io/

2. Выберите "PNG to ICO"

3. Загрузите ваше изображение логотипа

4. Скачайте архив с favicon

5. Распакуйте и скопируйте ВСЕ файлы в папку:
   C:\propjects\projects_cursor\fond3\static\images\

6. Дополнительно скопируйте оригинальный логотип туда же как:
   logo.png

7. Запустите сайт:
   
   python app.py
   Откройте http://127.0.0.1:5000

┌──────────────────────────────────────────────────────────────┐
│ ❓ ПРОБЛЕМЫ?                                                  │
└──────────────────────────────────────────────────────────────┘

• Логотип не виден?
  → Проверьте, что файл logo.png существует в static/images/
  → Очистите кеш браузера (Ctrl+F5)

• Favicon не меняется?
  → Favicon кешируется надолго - подождите 5-10 минут
  → Попробуйте режим инкогнито

• Скрипт не работает?
  → Установите Pillow: pip install Pillow
  → Проверьте путь к файлу

Подробная инструкция: см. LOGO_GUIDE.md
