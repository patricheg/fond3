# 📋 Миграция: Добавление категорий для сборов

## Описание

Добавлены категории для благотворительных сборов:

1. **Будущий чемпион** — гранты для детей и юношей
2. **Второй шанс** — оплата операций и восстановления
3. **Верность спорту** — поддержка ветеранов и тренеров

---

## 🚀 Как применить на production

### Шаг 1: Обновите код
```bash
git pull origin main
```

### Шаг 2: Запустите миграцию
```bash
python migrate_add_category.py
```

### Шаг 3: Перезапустите приложение
```bash
# Если используете systemd
sudo systemctl restart fond3

# Или просто перезапустите Flask
```

---

## 📝 Что изменилось

### 1. База данных
- Добавлено поле `category` в таблицу `fundraiser`
- Существующие сборы получают категорию "Второй шанс" по умолчанию

### 2. Админ-панель
- В форме добавления/редактирования сбора появился выпадающий список категорий
- Категория обязательна для заполнения

### 3. Публичная часть
- На главной странице в карточках сборов отображается категория
- На странице "Сборы" добавлены фильтры по категориям
- На детальной странице сбора отображается полное название категории

---

## 💡 Использование категорий

### В админке:
1. Откройте форму добавления/редактирования сбора
2. Выберите подходящую категорию из выпадающего списка
3. Сохраните изменения

### Для пользователей:
- На странице `/fundraisers` можно фильтровать сборы по категориям
- Клик на кнопку категории показывает только сборы этой категории
- Кнопка "Все категории" показывает все сборы

## 🔍 Проверка после миграции

1. Откройте админ-панель
2. Зайдите в "Сборы"
3. Отредактируйте сбор и убедитесь, что есть поле выбора категории
4. Откройте публичную страницу `/fundraisers`
5. Проверьте наличие фильтров по категориям
6. Убедитесь, что категории отображаются в карточках
