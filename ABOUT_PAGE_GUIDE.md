# Руководство по странице "О нас"

## Что добавлено

Добавлена новая страница "О нас" с возможностью редактирования через админ-панель.

### Основные возможности:

1. **Редактирование текстового контента**
   - Основной текст о фонде
   - Блок "Наша миссия"
   - Блок "Наше видение"

2. **Загрузка изображений**
   - Документы
   - Фотографии команды
   - Достижения
   - Любые другие изображения

3. **Управление через админ-панель**
   - Удобный редактор
   - Предпросмотр изображений
   - Удаление изображений одним кликом

4. **Просмотр изображений в полном размере**
   - Клик по изображению открывает модальное окно
   - Красивый overlay при наведении
   - Закрытие по клику или клавише ESC

## Установка и настройка

### Шаг 1: Миграция базы данных

Запустите скрипт миграции для создания таблицы AboutPage:

```bash
python migrate_about.py
```

Этот скрипт:
- Создаст новую таблицу `about_page` в базе данных
- Добавит начальную запись с примером контента

### Шаг 2: Доступ к странице

После миграции:

1. **Публичная страница**: доступна по адресу `/about`
2. **Редактирование**: в админ-панели выберите раздел "О нас"

## Использование

### Редактирование контента

1. Войдите в админ-панель
2. Перейдите в раздел "О нас" (иконка ℹ️)
3. Заполните поля:
   - **Заголовок страницы** - название страницы (обычно "О нас")
   - **Основной текст** - главная информация о фонде
   - **Наша миссия** - описание миссии организации
   - **Наше видение** - описание видения организации

### Загрузка изображений

1. Нажмите "Выбрать файлы" в разделе изображений
2. Выберите одно или несколько изображений
3. Увидите предпросмотр загружаемых файлов
4. Нажмите "Сохранить изменения"

**Поддерживаемые форматы:**
- PNG
- JPG/JPEG
- GIF
- WEBP

**Ограничения:**
- Максимальный размер файла: 5 МБ
- Можно загружать несколько файлов одновременно

### Удаление изображений

1. Найдите изображение в списке "Текущие изображения"
2. Нажмите кнопку "Удалить" под изображением
3. Подтвердите удаление

Изображение будет удалено сразу, без необходимости сохранять форму.

## Структура базы данных

Таблица `about_page` содержит следующие поля:

- `id` - уникальный идентификатор
- `title` - заголовок страницы
- `content` - основной текст
- `mission` - текст миссии
- `vision` - текст видения
- `images_json` - JSON-массив с путями к изображениям
- `updated_at` - дата последнего обновления

## Примечания

- Страница "О нас" - это singleton (всегда существует только одна запись)
- При первом обращении к странице создается запись с дефолтным контентом
- Все изображения хранятся в папке `static/uploads/`
- Изображения отображаются в виде красивой сетки на публичной странице

## Навигация

- В главное меню сайта (между "Новости" и "Админ")
- В боковое меню админ-панели (после "Турниры")
