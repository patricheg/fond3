# Руководство по загрузке изображений

## 📸 Новая возможность: загрузка изображений

Теперь вы можете загружать изображения прямо на сервер вместо использования внешних ссылок!

## ✨ Возможности

### 1. **Загрузка с компьютера**
- Выберите файл с вашего компьютера
- Поддерживаемые форматы: PNG, JPG, JPEG, GIF, WEBP
- Максимальный размер файла: 5 МБ

### 2. **Предпросмотр изображения**
- После выбора файла вы сразу увидите предпросмотр
- Проверьте, правильно ли выбрано изображение перед сохранением

### 3. **URL изображений (дополнительно)**
- Если не хотите загружать файл, можете указать URL
- Если загрузите файл, URL будет проигнорирован

### 4. **Автоматическое управление**
- При замене изображения старое автоматически удаляется
- При удалении записи изображение также удаляется с сервера

## 🎯 Как использовать

### Добавление нового материала

1. Перейдите в админ-панель: http://127.0.0.1:5000/admin
2. Выберите раздел (Сборы, Новости или Турниры)
3. Нажмите "Добавить"
4. Заполните все поля
5. В разделе "Загрузить изображение":
   - Нажмите кнопку выбора файла
   - Выберите изображение с компьютера
   - Увидите предпросмотр выбранного изображения
6. Нажмите "Сохранить"

### Редактирование существующего материала

1. В списке материалов нажмите на иконку редактирования (карандаш)
2. Увидите текущее изображение (если оно есть)
3. Для замены изображения:
   - Выберите новый файл
   - Старое изображение будет автоматически удалено после сохранения
4. Нажмите "Сохранить"

## 📁 Хранение изображений

- Все загруженные изображения сохраняются в папке: `static/uploads/`
- Каждому файлу присваивается уникальное имя
- Файлы автоматически удаляются при удалении записи

## ⚠️ Важные моменты

### Ограничения:
- **Максимальный размер:** 5 МБ на файл
- **Форматы:** только PNG, JPG, JPEG, GIF, WEBP
- **Рекомендуемые размеры:**
  - Сборы: 800×600 пикселей
  - Новости: 800×500 пикселей
  - Турниры: 800×600 пикселей

### Советы:
- Используйте качественные изображения
- Избегайте слишком больших файлов (оптимально 200-500 КБ)
- Изображения в альбомной ориентации выглядят лучше
- Перед загрузкой можете сжать изображение в онлайн-сервисах

## 🛠️ Техническая информация

### Валидация:
- Проверка типа файла на клиенте и сервере
- Проверка размера файла
- Автоматическая генерация уникальных имен

### Безопасность:
- Проверка расширений файлов
- Ограничение размера файла
- Сохранение только разрешенных типов

### Производительность:
- Изображения сжимаются браузером при загрузке
- Оптимизированная загрузка на страницах
- Lazy loading для больших списков

## 🔧 Устранение проблем

### Файл не загружается:
1. Проверьте размер файла (должен быть < 5 МБ)
2. Убедитесь, что формат поддерживается
3. Попробуйте другой браузер

### Изображение не отображается:
1. Проверьте, что файл был успешно загружен
2. Обновите страницу (Ctrl+F5)
3. Проверьте, что папка `static/uploads/` существует

### Старое изображение не удаляется:
- Изображения с внешних URL не удаляются
- Удаляются только файлы, загруженные на сервер

## 📝 Примеры использования

### Пример 1: Добавление сбора с фото спортсмена
1. Сделайте качественное фото спортсмена
2. Оптимизируйте его размер (рекомендуется до 500 КБ)
3. Загрузите через форму добавления сбора
4. Фото появится на карточке сбора и на детальной странице

### Пример 2: Новость с фото мероприятия
1. Выберите лучшее фото с турнира или мероприятия
2. Кадрируйте в альбомную ориентацию
3. Загрузите при создании новости
4. Фото будет показано в списке новостей и в самой статье

### Пример 3: Турнир с баннером
1. Создайте или найдите привлекательный баннер турнира
2. Размер желательно 800×600
3. Загрузите при создании турнира
4. Баннер привлечет внимание участников

## 🎨 Рекомендации по дизайну

### Для сборов:
- Используйте фото спортсмена в действии
- Показывайте эмоции и достижения
- Избегайте размытых или темных фото

### Для новостей:
- Выбирайте яркие и информативные фото
- Фото должно отражать суть новости
- Используйте горизонтальные фото

### Для турниров:
- Создавайте привлекательные баннеры
- Указывайте название турнира на изображении
- Используйте спортивную тематику
