# Благотворительный местный фонд помощи спортсменам

Веб-сайт для благотворительной помощи спортсменам и организации турниров.

## Возможности

- 📢 Публикация новостей
- 💰 Создание благотворительных сборов
- 🏆 Информация о турнирах
- 📄 **НОВИНКА: Страница "О нас"** - расскажите о вашем фонде!
- 🔐 Защищенная админ-панель
- 📊 База данных SQLite
- 🖼️ **Множественная загрузка изображений** - загружайте сразу несколько фото!
- 🎬 **Красивый слайдер** - автоматическая карусель для пролистывания изображений
- 🎓 **Галерея документов** - загружайте и показывайте важные документы с просмотром в полном размере
- 👁️ Предпросмотр всех изображений перед сохранением
- 🗑️ Автоматическое удаление старых изображений
- ◄ ► Навигация по слайдеру с кнопками и точками

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. (Для существующих установок) Запустите миграции базы данных:
```bash
python migrate_db.py
python migrate_about.py
```

3. Запустите приложение:
```bash
python app.py
```

4. Откройте браузер по адресу: `http://localhost:5000`

## Админ-панель

Для доступа к админ-панели перейдите по адресу: `http://localhost:5000/admin`

**Данные для входа по умолчанию:**
- Логин: `admin`
- Пароль: `SportFund2026!Secure`

⚠️ **Важно:** Сохраните эти данные в надежном месте! Кнопка входа в админ-панель скрыта от публичного доступа для безопасности.

## Структура проекта

- `app.py` - главный файл приложения
- `models.py` - модели базы данных
- `templates/` - HTML шаблоны
- `static/` - статические файлы (CSS, JS, изображения)
- `database.db` - база данных SQLite (создается автоматически)

## 🖼️ Множественная загрузка изображений

**НОВИНКА!** Теперь вы можете загружать **несколько изображений** для каждого материала:

1. В админ-панели найдите поле "Загрузить изображения"
2. Нажмите кнопку и **выберите сразу несколько файлов** (Ctrl/Cmd + клик)
3. Увидите предпросмотр **всех** выбранных изображений
4. При редактировании можете удалять ненужные и добавлять новые
5. Сохраните форму

### На сайте:
- Если загружено **одно** изображение - отображается как обычно
- Если загружено **несколько** - появляется **красивый слайдер** с кнопками навигации!
